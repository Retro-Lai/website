QUICK START
────────────────────────────────────────
1. Unzip the folder.
2. Double-click  index.html  — it opens in your web browser. That's your
   site, running, right now. (It needs internet only to load the font.)
3. Open any .html file in a plain text editor (Notepad, TextEdit, or a free
   one like VS Code). Look for  <!-- EDIT: ... -->  comments — that's exactly
   where your own words go.
4. The brand is "MAYA.SYS / Maya Rivera" everywhere — replace it with yours.
5. Want different colours? Open  style.css  and edit the  :root  block at the
   very top. Change a few hex codes and the WHOLE site re-colours at once.

Full walkthroughs are in the  docs/  folder and in  Setup-Guide.pdf.

────────────────────────────────────────
HOW TO PUBLISH (pick any — all free)
────────────────────────────────────────
• Easiest: drag the whole folder onto  https://app.netlify.com/drop
  → live instantly with a free link.
• Or: GitHub Pages / Cloudflare Pages / Vercel — upload the folder.
• Or: any normal web host — upload the files to public_html via FTP/cPanel.
No server or database required — these are plain static files.
See  docs/PUBLISH.md  for click-by-click steps.

────────────────────────────────────────
THE CONTACT FORM
────────────────────────────────────────
The contact form is front-end only — by itself it does NOT send email.
Connect it (free) in one of two ways:
  A) Formspree — paste your form URL into the <form action="..."> tag.
  B) mailto — turn the Send button into a link that opens the visitor's
     email app.
Both are explained step-by-step in  docs/PUBLISH.md.
